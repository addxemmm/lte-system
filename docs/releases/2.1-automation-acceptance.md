## 使用与边界 / Use and boundaries

```bash
docker pull addxemmm/lte-system:2.1
# Prefer exact digest for reproducible deployment selection:
docker pull addxemmm/lte-system@sha256:09887dcaa527ea5dd503a84705ae11fda0e77b56096186407680b139d150d35e
```
