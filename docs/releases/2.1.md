# LTE System 2.1 — Web console and automated releases / Web 管理台与自动发布

## 中文

### 变化
- 前后端同一 Go 二进制和容器：六页中英管理台、深浅主题、响应式布局、SVG 拓扑、键盘交互和操作确认。
- 默认仅开放管理台 8080；独立完整 API 8081 需显式启用。配置文件固定 Bearer Token 非空时启用，空值开放访问。
- 同源管理网关沿用鉴权并限制路由，Token 仅驻留浏览器内存；公开镜像不包含部署用 Token 或实际数据卷。
- `VERSION` 编译进运行程序；发布校验版本 tag、完整 commit、OCI 标签及镜像 digest。
- GitHub Actions 提供 verify/build/publish/resume。普通提交只测试，版本 tag 自动发布；中断后恢复既有匹配镜像，不覆盖正式版本。

### 兼容性与部署
运行版本保持用户指定的 **2.1**，首次正式标签为 `v2.1`。历史 `archive/v1-python` 仅为归档。旧客户端若仍连接 8081，请配置 `LTE_EXPOSE_API=true` 并在 bridge 模式叠加测试 override。公开镜像仅支持本次验证的 `linux/amd64`。

发布不自动部署服务器、不启动小区、不改动 GSM。使用公开镜像前，配置私有 YAML、网络访问限制及持久化数据卷；不要将空 Token 管理台直接暴露公网。现场继续保留已停止的旧测试容器，除非另行要求部署。

### 测试与边界
发布工作流以 Go/vet/race、Python/JS/shell、完整镜像七项 CTest、无硬件管理面 smoke 为门禁。镜像验证覆盖版本标签、默认 API 关闭、双端口鉴权、静态页面、非敏感元数据和对应源码存在。具体结果和包清单见附件；这些测试不代表手机注册、RF、Internet 或吞吐量验收。

完整镜像保留匹配的 patched srsRAN 源码、pySIM 源码和构建材料；第三方/固件按其自身许可分发，见镜像内 `THIRD_PARTY_NOTICES.md`。当前提供 SHA-256 和 Debian 包清单，尚未生成签名、标准 SBOM 或供应链证明；浮动系统/Python依赖也不保证逐位可复现。

## English

### Changes
- Embed six bilingual console pages in the same Go binary/container, with themes, responsive layout, SVG topology, keyboard support and action confirmations.
- Expose console 8080 by default; opt in to independent full API 8081. A nonempty configured static Bearer token enables authentication; an empty token allows anonymous access.
- Keep a restricted authenticated same-origin management gateway and memory-only browser tokens. Published images contain neither deployment credentials nor live data volumes.
- Embed `VERSION`; validate the Git tag, full source commit, OCI labels and registry digest.
- Add verify/build/publish/resume workflows. Ordinary pushes only test; version tags publish. Resume verifies an existing matching image instead of overwriting a released version.

### Compatibility and deployment
Retain the requested runtime version **2.1**, with first formal tag `v2.1`. `archive/v1-python` remains historical only. Legacy 8081 clients require `LTE_EXPOSE_API=true` plus the bridge test override where applicable. This release targets `linux/amd64` only.

Publication does not deploy, start a cell or change GSM. Configure private YAML, restricted network access and persistent data before use; do not expose anonymous management to the Internet. The stopped server test container stays unchanged unless deployment is separately requested.

### Validation and limitations
Required gates cover Go/vet/race, Python/JS/shell, seven full-image CTests and hardware-free management smoke. Image checks cover identity, default API-off behavior, dual-port auth, pages, nonsecret metadata and source availability. Attachments record results and package inventory; no handset, RF, Internet or throughput acceptance is implied.

The full image carries matching patched srsRAN source, pySIM source and build materials. Third-party software/firmware retain their own licensing; see bundled notices. SHA-256 and Debian package inventory are provided, but signatures, a standard SBOM and supply-chain attestations are not generated yet. Floating OS/Python dependencies do not guarantee bit-for-bit reproducibility.
