# LTE 默认端口与服务器迁移 / Default ports and server migration

## 中文

- 用户指定默认端口：**前端 18081，后端 8081**。前端始终启用；独立后端默认不监听/不发布，仅在 `LTE_EXPOSE_API=true` 或测试 override 时开放。前端有限管理网关不受独立后端关闭影响，鉴权规则保持不变。
- 源码默认值、配置样例、两种 Compose 基础文件、Dockerfiles、发布 smoke、测试和当前文档同步；Postman 完整集合仍指向 `http://HOST:8081`，只读集合也可使用 `http://HOST:18081`。
- 服务器已从旧 `ltesystem-dep:2.1` / `afb2118aaeca` 换为正式 `addxemmm/lte-system:2.1`，固定 digest `sha256:09887dcaa527ea5dd503a84705ae11fda0e77b56096186407680b139d150d35e`，镜像 ID `326bc798e3bc`。已发布镜像仍对应源码 `a449d7cc57e79b5497525a6e12ebec3ab6737f7e`，本次使用环境变量调整监听，不重建/覆盖 Hub 2.1，不移动 Git tag。
- 服务器最初的 8080 与 GSM 冲突，曾临时使用 8083；现按用户要求改为 `18081:18081`，API 保持 `8081:8081`。GSM 保持 8080/8082，容器及启动时间未变。
- LAN 首页和 `/ui-config.json` 返回 200，元数据报告 `ui_port=18081`、`api_port=8081`、`api_exposed=true`。UI/API 小区状态均停止，容器仅 Go 管理进程；旧宿主 8083 已无监听。沿用现场空 Token 配置，仅应在可信管理网络访问。
- 替换前备份原 `docker_lte-data`，19 个既有文件逐一哈希校验一致。旧 LTE 容器/镜像已替换清理，不保留回滚镜像；仅保留当前 LTE/GSM 镜像和容器，构建缓存 0 B；所有数据卷、配置和数据备份保留。
- 正式镜像本地未压缩大小 1,388,256,440 字节，Hub 压缩大小 440,767,361 字节。大小差异不是可删除缓存的测量。

### 使用已发布 2.1 镜像

显式设置 `LTE_UI_LISTEN=0.0.0.0:18081`，并发布 `18081:18081`；完整 API 测试另设 `LTE_EXPOSE_API=true`、`LTE_LISTEN=0.0.0.0:8081` 与 `8081:8081`。保留原配置/数据卷及管理入口。新 Compose 已设置新 UI 地址；已有私有 override 若仍指定旧地址，需同步更新。Docker 显示裸 `8080/tcp` 是原镜像的 EXPOSE 元数据，并非宿主映射。

## English

- Defaults are **console 18081 and API 8081**. The console always starts; the independent API remains opt-in. The console's limited same-origin gateway and authentication semantics are unchanged.
- Source defaults, examples, Compose, Dockerfiles, release smoke, tests and current documentation agree. Full Postman collections keep `http://HOST:8081`; read-only checks may use `http://HOST:18081`.
- The server now uses the formal 2.1 image at the exact digest and source revision above. Runtime overrides select the new ports; this does not rebuild/overwrite the published image or move v2.1. Its old EXPOSE 8080 is inert metadata, not an active published port.
- GSM occupies 8080/8082 and was untouched. LTE's temporary 8083 was replaced with 18081; API remains 8081. LAN checks passed and public metadata reports the new ports. The LTE cell remains stopped with only the Go management process running. Existing empty-token access is retained for the trusted management network.
- Original data/configuration and all backups remain. All 19 existing data files matched their backup hashes; obsolete LTE image/container were removed, with no rollback image retained. Current LTE/GSM images remain, and Docker build cache is zero.
- Compressed registry size and local unpacked image size are different accounting measures, not evidence of reclaimable cache. No RF/handset/Internet acceptance is claimed.

See [deployment](DEPLOY.md), [console](WEB_UI.md) and [publication](RELEASING.md).
