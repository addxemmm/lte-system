## 尚未覆盖与后续工作 / Remaining scope

1. 未进行真实小区发射、终端入网、数据面吞吐或实际写卡；API 健康不等于端到端 RF 验证。
   Real transmission, UE attach, data-plane throughput and physical SIM programming were not tested. API health is not end-to-end RF validation.
2. Go/基础镜像/系统和 Python 依赖的全量升级、漏洞扫描及内容锁定需单独安排；此次未改变已有 srsRAN/pySIM 版本。
   Full Go/base/system/Python upgrades, vulnerability scanning and content pinning remain separate work. Existing srsRAN/pySIM versions were retained.
3. privileged/host 网络仍存在，默认回环降低暴露；LAN 访问须配置令牌、网络访问控制及 TLS/SSH。
   Privileged host networking remains. Loopback defaults reduce exposure; LAN use needs tokens, network controls and TLS/SSH.
4. 进程内订户锁不覆盖外部 EPC 写回；异常掉电后的网络规则所有权也未持久化。建议停止小区后修改卡库，并人工复核崩溃遗留规则。
   Subscriber locking does not cover external EPC writes; network-rule ownership is not persisted across crashes. Stop the cell before database changes and inspect crash-leftover rules.
